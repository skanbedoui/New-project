# Customer Churn Prediction using Machine Learning

CS280 / CS485 AI lab project for supervised binary classification of customer churn.

## Project Overview

The goal is to predict whether a customer will churn using demographic, subscription, usage, support, payment, and spending features. The target variable is `Churn`, where `1` means the customer churned and `0` means the customer stayed.

The project compares exactly three models:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest Classifier

The final model is selected using business-aware metrics, especially F1-score and recall, because missing a true churner can be costly.

## Dataset

The dataset files must remain in the `dataset/` folder:

- `dataset/customer_churn_dataset-training-master.csv`
- `dataset/customer_churn_dataset-testing-master.csv`

The notebook and dashboard use relative paths, so no machine-specific file paths are required.

The `dataset/` folder and `.venv/` virtual environment are intentionally ignored by git because they are local or large environment files.

## Setup

Create and activate a virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Notebook

```bash
jupyter notebook customer_churn_lab_project.ipynb
```

Run all notebook cells from top to bottom. The notebook generates:

- `models/churn_prediction_model.pkl`
- `outputs/baseline_metrics.csv`
- `outputs/model_metrics.csv`
- `outputs/tuning_summary.csv`
- `outputs/roc_curves.csv`
- `outputs/confusion_matrices.csv`
- `outputs/feature_importance.csv`
- `outputs/sample_predictions.csv`
- `outputs/data_profile.json`

## Run the Dashboard

After running the notebook once:

```bash
streamlit run streamlit_dashboard.py
```

The dashboard loads the saved preprocessing-plus-model pipeline from `models/churn_prediction_model.pkl` and supports model comparison, dataset preview, and single-customer churn inference.
